▶HIGHos.environ 竞态条件 — 多线程模型下载ocr_engine.py:146-169

证据

def _hf_download_with_mirror(repo_id, local_dir, progress_cb):
    original = os.environ.get("HF_ENDPOINT")
    try:
        os.environ["HF_ENDPOINT"] = original  # 修改全局环境变量
    finally:
        if original is not None:
            os.environ["HF_ENDPOINT"] = original  # 可能删除另一个下载刚设置的值

影响

并发下载同时修改 os.environ["HF_ENDPOINT"]，finally 块可能删除另一个下载刚设置的值，导致模型下载失败或使用错误镜像源。

修复：使用 threading.Lock 保护环境变量修改，或使用 huggingface_hub 的 endpoint 参数。
▶HIGHmodel_manager TOCTOU 竞态model_manager.py:190-198

证据

async def predict(self, model_id, predict_fn):
    if selected_id != self.active_model_id:
        await self.activate(selected_id)  # 释放锁
    async with self._predict_lock:       # 间隙：另一个协程可激活不同模型

影响

activate 释放锁后到 predict 获取锁前，另一个请求可激活不同模型，导致当前模型被卸载。

修复：重构为单一锁覆盖 activate + predict，或将 predict_lock 获取移到 activate 调用前。
